snens: документация для агентов
================================

Первичный источник сведений о самом snens. Файлы — обычный текст по стабильным
URL, без вёрстки и JS: читай как есть (`fetch <url>` или `run curl -s <url>`).
Этот же текст в вёрстке для человека — https://snens.svuvi.ch/docs/install.html

Что такое snens: ядро агента-харнесса на Rust (исходники
https://git.svuvi.ch/svuvich/snens). Ядро держит цикл «запрос модели → вызов
инструмента → результат», всё остальное вынесено наружу. Инструменты — отдельные
программы (argv + stdin), ядро находит их в каталоге тулов и описывает модели по
их же `--help` и `schema.json`. Два инструмента вшиты в ядро: `run` (shell-команда)
и `ctx` (рабочий контекст). Инстанс — файлы: `soul.md`, `user.md`, `memory.md`,
`skills/`, `tickets/`; они уезжают в каждую сессию.

Файлы
-----

quickstart.txt
  Цикл хода, `run` и `ctx`, переменные окружения, каталоги, файлы инстанса.
  https://snens.svuvi.ch/llm/quickstart.txt

tools.txt
  Справочник по всем инструментам: полный `--help` и схемы. Генерируется из
  исходников, руками не правится.
  https://snens.svuvi.ch/llm/tools.txt

plugins.txt
  Расширения: плагин долгой памяти, скиллы (`SKILL.md`), свой тул как программа.
  https://snens.svuvi.ch/llm/plugins.txt

practices.txt
  Контекст и его сжатие, подагенты, тикеты, привилегии, частые ошибки.
  https://snens.svuvi.ch/llm/practices.txt

Правила чтения
--------------

- Текст читай целиком; код — нет: сперва `grep -n <символ>` (тул `grep`), потом
  `read --offset N --limit M` по найденному месту.
- Факты здесь собраны из исходников (`src/`, `tools/*`, `docs/`), а не пересказаны
  по памяти. Расхождение с кодом — ошибка здесь, а не в коде.
- Версий нет: файлы описывают текущий `main` и выкладываются скриптом
  `scripts/site-publish.sh` вместе с сайтом.
