# С чего начать

Через десять минут у тебя будет открытое приложение, ключ доступа к модели и первая
выполненная задача — без единой команды в терминале.

## 1. Скачать и поставить

[Скачать для Windows]({{INSTALLER}}){.cta}

Установщик кладёт программу в твой профиль пользователя, права администратора не нужны
(`%LOCALAPPDATA%\snens`), и сразу её запускает. В трее — области справа внизу, рядом с
часами — появляется значок snens.

Вместе с окном работает **ядро**: невидимая программа, которая держит связь с моделью и
исполняет команды на твоей машине. Окно — только витрина ядра.

Крестик окна программу не выключает: окно прячется в трей, работа идёт дальше. Полностью
закрыть — «Выход (остановит ядро)» в меню значка; это же перед установкой новой версии.

## 2. Получить ключ

Ответы пишет модель — чужая программа на сервере провайдера. Провайдер — компания, которая эту
модель тебе продаёт. Пускают туда по **API-ключу**: длинный пароль из букв и цифр вида
`sk-or-v1-9f3c…`. Сам ключ бесплатный, а деньги списываются с твоего аккаунта у провайдера за
каждый кусок прочитанного и написанного текста.

Один пример: OpenRouter — регистрация по почте или через Google, страница **Keys**, кнопка
**Create Key**, готовый ключ копируешь сразу (второй раз его не покажут).

Провайдеров несколько, у каждого свой адрес и свои названия моделей: [Где взять
ключ](/docs/keys.html).

## 3. Вставить ключ

**Через окно.** Внизу слева кнопка «настройки», раздел «провайдеры», кнопка «+ профиль» (или
готовая кнопка `+ openrouter`). В полях адрес, название модели и ключ. Сохранил — работает со
следующего хода, перезапускать ничего не надо.

**Через файл.** Настроек два текстовых файла, оба в одной папке: на Windows
`%APPDATA%\snens\`, на Linux и macOS `~/.config/snens/`. Ключ — в `.env`, остальное — в
`config.toml`: файл настроек без секрета можно кому-то показать.

`.env` — ровно одна строка, без кавычек и пробелов:

```sh
SNENS_API_KEY=sk-or-v1-9f3cтвойключ
```

`config.toml` — адрес провайдера и имя модели:

```toml
base_url = "https://openrouter.ai/api/v1"
model = "deepseek/deepseek-v4.1-flash-1017"
```

Две строки, обе в кавычках, без `/chat/completions` на конце адреса.

## 4. Первая задача

Пиши обычными словами, как поставил бы задачу человеку.

- «Разберись, почему на диске кончилось место, и покажи, что занимает больше всего».
- «В папке на рабочем столе двадцать счетов в PDF — сведи их в таблицу: дата, сумма, поставщик».
- «Найди в этих логах все ошибки за прошлую неделю и напиши короткое резюме».

Агент сам решает, какие файлы и команды ему нужны, и показывает, что делает. Разрешение он
спрашивает там, где нужны права администратора: приходит запрос с текстом команды и кнопками
«разрешить» / «отклонить». Внутри твоей папки действует без спроса — подключил, значит
доверяешь; ограничивать его надо отдельной учётной записью или контейнером.

## 5. Если что-то не так

Ошибка видна прямо в окне, под задачей: чаще всего «ключ не найден» (не сохранился `.env`) или
«401» — ключ скопирован не полностью или на аккаунте провайдера кончились деньги.

Полный журнал каждой сессии лежит в папке данных, `sessions/<id>.jsonl`: на Windows
`%APPDATA%\snens\sessions\`, на Linux и macOS `~/.local/share/snens/sessions/`. Это текст —
открой блокнотом и посмотри, что агент отправил и получил.

Остальные отказы с причинами и лечением: [Если не работает](/docs/faq.html).
