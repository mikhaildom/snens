# snens

Агент, который работает на вашей машине: терминал, файлы, поиск, память,
подагенты. Ядро на Rust, инструменты — отдельные программы.

[Скачать для Windows]({{INSTALLER}}){.cta}

## Что он делает

Получает задачу, сам решает, какая команда или инструмент нужен, выполняет и
показывает результат. Сессия — файл журнала: её можно пересмотреть, продолжить
или отдать ревью.

Работает в терминале (`snens tui`), в веб-клиенте (`snens serve`) и в десктопном
окне. Модель — любая OpenAI-совместимая: свой адрес, свой ключ.

## Поставить и запустить

1. Установщик для Windows — кнопкой выше; Linux собирается из исходников.
2. Ключ и адрес провайдера — в `~/.config/snens/.env` и `config.toml`.
3. `snens run "что нужно сделать"` или `snens tui`.

Подробно: [установка](/docs/install.html) · [первый запуск](/docs/first-run.html) ·
[провайдеры](/docs/providers.html).

## Как устроено

| часть | что это |
|---|---|
| ядро | цикл «запрос модели → вызов инструмента → результат», один бинарь |
| инструменты | отдельные программы: `read`, `edit`, `grep`, `run`, `agent`, … — контракт в `--help` |
| инстанс | каталог с `soul.md`, `user.md`, `memory.md`, скиллами и тикетами |
| поверхности | TUI, веб-клиент, десктоп — одно ядро, разные окна |
