snens для Windows 7 (x64)
=========================

Что внутри
----------
snens.exe                ядро (агент, HTTP API, отдаёт веб-клиент)
tools\<тул>\<тул>.exe    инструменты агента (read, edit, grep, fetch, memory, ...)
web\                     собранный веб-клиент, ядро отдаёт его само
snens-desktop.exe        приложение snens - своё окно, интернет-браузер не нужен
WebView2\                движок окна (WebView2 109, последний для Windows 7)
WebView2Loader.dll,
combase.dll,
api-ms-win-core-winrt-error-l1-1-0.dll
                         нужны snens-desktop.exe, удалять нельзя
snens-app.exe            запасное окно через Chrome 109 / Supermium
start-snens.cmd          запуск: ядро в консоли + обычный браузер
README.txt               этот файл

Что нужно на Windows 7
----------------------
1. Windows 7 SP1 x64. Проверено на машине без KB2533623 и KB3125574: ядро и
   окно работают (WebView2Loader.dll в архиве поправлен под такую систему).
2. Браузер. Лучше Supermium (свежий Chromium для Win7, поддерживает всё).
   Firefox ESR 115 тоже работает, но в нём не будет части подсветок и
   всплывающих панелей (нет CSS :has). Chrome 109 подходит.
3. Доступ в интернет (к API модели). Сертификаты встроены в snens, системные
   корневые сертификаты Windows 7 не нужны.

Первый запуск
-------------
1. Распаковать архив, например в C:\snens  (путь без русских букв надёжнее).
2. Создать папку %APPDATA%\snens  (Win+R -> %APPDATA% -> новая папка snens).
3. В ней файл config.toml (Блокнот, сохранить как UTF-8):

     base_url = "https://провайдер.example/v1"
     model = "имя-модели"

   base_url без /chat/completions.
4. Там же файл .env с ключом (в Блокноте имя писать в кавычках: ".env"):

     SNENS_API_KEY=sk-...

5. Запустить snens-desktop.exe двойным щелчком (удобно сделать ярлык на
   рабочем столе). Это и есть приложение: своё окно, ядро внутри, браузер
   не нужен. Крестик прячет окно в трей (значок у часов), выход - из меню
   значка.
   Папку WebView2 держать рядом с snens-desktop.exe: на Windows 7 движок
   окна не ставится отдельно, он едет с программой. Это WebView2 109.0.1518.140
   из каталога Центра обновления Microsoft (автономный установщик Edge 109 x64,
   из него взята папка Chrome-bin9.0.1518.140).

   Запасные способы:
   - snens-app.exe - то же окно, но рисует его Chrome 109 / Supermium /
     Edge 109 (один из них нужен). Подключение к ядру само. Ядро гаснет
     вместе с окном. Если окно спросит адрес и код: адрес
     http://127.0.0.1:7420, новый код: snens.exe pair (5 минут);
   - start-snens.cmd - ядро в консольном окне и обычный браузер.
   Одновременно работает только одно ядро: перед запуском другого способа
   закройте предыдущий.

Запасной ключ
-------------
Можно завести второй профиль с другим ключом (например, OpenRouter):

     snens.exe providers key openrouter -

   вставить ключ, Enter, потом Ctrl+Z и Enter. Профиль openrouter уже
   должен быть в config.toml ([providers.openrouter] с base_url и model).

Если ключ активного профиля перестал работать (отказ по ключу или оплате,
лимит, провайдер или сеть не отвечают), snens сам повторит запрос через
запасной профиль, сделает его активным и напишет об этом в окне. Вернуть
основной: snens.exe providers activate <имя> или в настройках окна.
Выбрать запасной явно - строка в config.toml:  fallback_provider = "имя"
Не переключаться никогда:                      fallback_provider = "none"

Другой порт: start-snens.cmd 7500

Консольный режим
----------------
   snens.exe tui        диалог в консоли (построчный ввод)
   snens.exe run "..."  одна задача
Цвета в консоли Windows 7 выключаются сами (она не понимает ANSI).
Шрифт консоли поставить Lucida Console или Consolas, иначе русский текст
может отображаться квадратиками.

Удалённый доступ к ноутбуку
---------------------------
AnyDesk: проверьте, что версия ставится на Windows 7 (если свежая не
встаёт - старая 7.x). Ядро слушает только 127.0.0.1, наружу не открыто.
Чтобы открыть клиент с другого компьютера в сети:
   snens.exe serve --listen <IP ноутбука в локальной сети>:7420 --allow-remote
и разрешить порт в брандмауэре; подключение - по коду из snens.exe pair.

Если не запускается
-------------------
- "Точка входа в процедуру ... не найдена в библиотеке KERNEL32.dll" -
  поставить обновления (п.1) и сообщить имя функции.
- Окно "snens serve" сразу закрывается - запустить в cmd вручную:
     snens.exe serve
  и посмотреть текст ошибки.
- Белая страница в браузере - нажать Ctrl+F5; если не помогло - открыть
  консоль браузера (F12) и прислать ошибку.
