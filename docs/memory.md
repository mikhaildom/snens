# Долгая память

Механизмов два, и они не заменяют друг друга.

**Карточка `memory.md`** — факты в системном префиксе: правит агент, стоит
токенов каждый ход, поэтому только то, что нужно всегда.

**Плагин `memory`** — бинарь `tools/memory`, один файл SQLite (FTS5 +
sqlite-vec), без демона. Ядро знает только argv-контракт:

```sh
memory recall <текст>        # → строки фактов (пусто = нечего сказать)
memory retain < ход.json     # {"user":"…","assistant":"…"} → локальная очередь
memory flush                 # очередь → факты (LLM + эмбеддинги), тут и только тут сеть
memory stats | reindex | forget <uid>
```

`retain` не делает ни одного сетевого вызова: он кладёт ход в локальную очередь,
и всё. Сеть появляется на `flush`, который зовут извне — таймером или руками.

Включён по умолчанию (`[memory]` нет → `enabled = true`), конфиг —
`~/.config/snens/memory.toml`, провайдер OpenAI-совместимый. Справка едет
по режиму `memory.recall` (`always`/`session`/`off`) и остаётся короткой:
она живёт в префиксе до конца сессии.

Устройство, конфиг и грабли — `snens-memory/README.md`. Для человека —
`site/snens.svuvi.ch/content/memory.md`.
